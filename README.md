# matthewfails-site

Source for Matthew D. Fails's academic website, live at https://matthewfails.github.io/matthewfails-site/ (Hugo + Hugo Blox + Pagefind, deployed to GitHub Pages).
See **UPDATING.md** to add papers or talks and edit pages, and **WEBSITE_PRINCIPLES.md** for architecture.

Pushing to `main` publishes automatically (GitHub Actions → GitHub Pages, about 2 minutes). See **CLAUDE.md** for current status, owner decisions, and the build/preview workflow.
